CC214: DATA STRUCTURES & ALGORITHMS - MODULE 7 
SORTING, SEARCHING, AND HASHING - ANSWER SHEET

1. It refers to arranging data in a particular format.
   ANSWER: Sorting

2. If a sorting algorithm, after sorting the contents, does not
   change the sequence of similar content in which they appear,
   it is called
   ANSWER: Stable Sorting Algorithm (Stable Sort)

3. If a sorting algorithm, after sorting the contents, changes
   the sequence of similar content in which they appear, it is
   called
   ANSWER: Unstable Sorting Algorithm (Unstable Sort)

4. A sequence of values is said to be in ___________, if the
   successive element is greater than the previous one.
   ANSWER: Ascending Order

5. A sequence of values is said to be in ___________, if the
   successive element is less than the current one.
   ANSWER: Descending Order

6. A sequence of values is said to be in ___________, if the
   successive element is less than or equal to its previous
   element in the sequence.
   ANSWER: Non-Increasing Order

7. A sequence of values is said to be in ___________, if the
   successive element is greater than or equal to its previous
   element in the sequence.
   ANSWER: Non-Decreasing Order

8. This sorting algorithm is comparison-based algorithm in which
   each pair of adjacent elements is compared and the elements
   are swapped if they are not in order.
   ANSWER: Bubble Sort

9. The array is searched sequentially and unsorted items are
   moved and inserted into the sorted sub-list (in the same
   array).
   ANSWER: Insertion Sort

10. This sorting algorithm is an in-place comparison-based
    algorithm in which the list is divided into two parts, the
    sorted part and the unsorted part.
    ANSWER: Selection Sort

11. It is a sorting technique based on divide and conquer
    technique.
    ANSWER: Merge Sort

12. This algorithm uses insertion sort on a widely spread
    elements, first to sort them and then sorts the less widely
    spaced elements.
    ANSWER: Shell Sort

13. It is a highly efficient sorting algorithm and is based on
    partitioning of array of data into smaller arrays.
    ANSWER: Quick Sort

14. It is the process of finding a given value position in a
    list of values.
    ANSWER: Searching

15. It is the process of mapping large amount of data item to
    smaller table with the help of hashing function.
    ANSWER: Hashing
