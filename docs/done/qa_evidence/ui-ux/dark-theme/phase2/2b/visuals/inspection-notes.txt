- Avatar close-ups: both render as clean circles with legible white initials.
  Observed trade-off (recorded honestly): the dark avatar's circle EDGE is
  subtle against the near-black topbar (oklch 0.32 fill on the 0.225 surface,
  roughly 1.5:1 boundary contrast). The informational content (white initials,
  ~9:1) is fully legible, the avatar is not an interactive control so WCAG
  1.4.11 does not require a 3:1 boundary, and 0.32 is exactly the established
  raised-dark rung (dark --line / --login-border) rather than a new invented
  elevation. Raising the fill further (e.g. the 0.42 slate-300 rung) would make
  the circle more prominent at the cost of a brighter dot in the calm topbar;
  left as-is and flagged for the owner as optional Stage-2D-style polish if a
  more defined edge is wanted.
