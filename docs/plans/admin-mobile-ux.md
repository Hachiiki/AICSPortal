# Admin mobile portal redesign

- Use the student and faculty mobile portal as the reference for navigation, typography, spacing, and dashboard hierarchy.
- Adapt the admin home, navigation, and management views for touch and narrow screens. Preserve admin actions, access controls, and desktop workflows.
- Capture comparable baseline and updated screens with synthetic data. Check mobile light and dark modes, narrow widths, navigation and representative management workflows, plus student and faculty regressions.
- Review the rendered work with the design council and iterate on its findings. Run lint, typecheck, and the production build before review.
